# B3-001 Evaluator Rubric — Repository Research

Version: 0.1

## Question under evaluation

Explain how the project distinguishes cache efficiency from cognitive/context efficiency, identify the canonical runtime resource classes directly implicated by that distinction, and cite the minimum repository evidence needed to support the answer.

## Scoring

Total: 100 points.

### A. Core distinction — 35

Full credit requires the answer to distinguish:
- economic/provider cache reuse from semantic need;
- the fact that cached material can still occupy logical/model-visible context;
- the project principle that cheaper reuse does not mean the information should be supplied at all.

### B. Canonical resource classes — 25

Full credit requires use of the repository's canonical resource model rather than invented categories. Relevant classes should include at least:
- R1 Information;
- R2 Instructions when applicable;
- R4 Cache/reuse;
- R11 Infrastructure/serving where physical cache economics are discussed;
- R12 Outcome/economics for measured utility.

Do not require every class if the answer correctly limits itself to those directly implicated.

### C. Evidence grounding — 25

Full credit requires precise repository paths/sections and minimal sufficient evidence. Opening or citing large numbers of irrelevant files should reduce evidence-precision scoring.

### D. Epistemic discipline — 15

Full credit requires:
- no fabricated repository claims;
- inference labelled as inference;
- unknowns acknowledged where the repository does not establish a fact.

## Failure conditions

The run fails regardless of numerical score if:
- it materially reverses the cache-vs-context distinction;
- it invents canonical resource classes;
- it claims provider behaviour as a project fact without evidence;
- it modifies repository files despite the research-only task.

## Suggested success threshold

85/100 with no failure condition.
